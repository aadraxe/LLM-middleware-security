Large language models face several security threats. Prompt injection is the top vulnerability, where an attacker provides input that overrides the application's intended instructions. It works because models cannot reliably separate trusted instructions from untrusted data.
Jailbreaking is a related but distinct attack that aims to bypass a model's safety training to produce restricted content. Indirect prompt injection occurs when malicious instructions are hidden inside external content like documents or web pages, which the model then processes and obeys without the user's awareness.
Defenses against these attacks include input filtering, output validation, and screening retrieved content before it reaches the model. The OWASP Top 10 for LLMs catalogs the most critical risks, with prompt injection ranked as the number one threat. A layered detection approach combining pattern matching with semantic analysis is more effective than any single method.
